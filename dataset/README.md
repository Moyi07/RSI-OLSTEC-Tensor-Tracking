# WAAM-ViD Reference Data

The real-video experiments use reference data from the Wire Arc Additive Manufacturing Video Dataset (WAAM-ViD). The raw video and metadata files are not redistributed in this repository.

## Dataset Citation

Seemal Asif, Wojciech Suder, Keun Woo Kim, Alexander Kamerkar, Tzu-En Chiu, and Ibrahim Abdi (2025), *Data for Wire Arc Additive Manufacturing Video Dataset (WAAM-ViD)*, Cranfield University.

- DOI: [https://doi.org/10.57996/cran.ceres-2763](https://doi.org/10.57996/cran.ceres-2763)
- Related project repository: [https://github.com/IFRA-Cranfield/WAAM-ViD](https://github.com/IFRA-Cranfield/WAAM-ViD)
- Data license: [Creative Commons Attribution-NonCommercial-NoDerivatives 4.0 International](https://creativecommons.org/licenses/by-nc-nd/4.0/)

The data license above applies to the WAAM-ViD files. These files are not covered by the MIT License of the RSI-OLSTEC code repository.

## Derived Visual Outputs

The real-video experiment scripts generate qualitative figures from the
locally obtained WAAM-ViD sequence. In particular,
`Fig_Running_Final.fig` and `Fig_MultiFrame_Matrix_R2.fig` are generated by
the R2 workflow, while `Fig_MultiFrame_Matrix_R3.fig` is generated by the R3
workflow. These figures are experimental outputs of the tracking algorithms
and do not replace the source dataset. They can be regenerated by placing the
required WAAM-ViD files at the paths below and rerunning the corresponding
scripts. Any redistribution of these derived visual outputs remains subject
to the applicable terms of the WAAM-ViD data license.
Accordingly, the public repository does not redistribute these three editable
FIG files or `R3_stats.mat`, which also contains representative input and
reconstruction arrays. They remain local outputs of the reproducible
experiment scripts.

## Required Local Files

Download the official dataset and place the following files at the exact paths shown:

```text
dataset/video/250312-110206-video_1.mp4
dataset/WAMVID_metadata.csv
```

These inputs are required by `Exp_R1.m`, `Exp_R2.m`, `Exp_R3.m`, and `Export_R2_Supplementary_Video.m`. Synthetic Experiments S1--S6 do not require WAAM-ViD data.

## Integrity Information

The local video input used to produce the reported results had the following identifier:

```text
Filename: 250312-110206-video_1.mp4
Size: 31,674,475 bytes
SHA-256: FB31C89F55186B7DA76FA871B3CF1259C5C964E48679D398B6BAE17B957CE7E6
```

This hash identifies the local experimental input. It does not independently establish byte-for-byte identity with the copy inside the official WAAM-ViD archive. Because that identity has not been independently verified, the video is not redistributed or described as an unmodified official copy.

The official metadata bitstream is identified by:

```text
Filename: WAMVID_metadata.csv
Size: 483,605 bytes
MD5: 029ad46bf08db32a1bce743cccca5377
```

The local analysis copy used Unix line endings and therefore had a different byte-level checksum. After line-ending normalization, its textual content was verified to match the official metadata file. This formatting difference does not alter the table values parsed by MATLAB. Users should download and use the official metadata file.
