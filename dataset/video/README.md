# Local Video Placement

WAAM-ViD video files are not redistributed in this repository. Download the official dataset from:

[https://doi.org/10.57996/cran.ceres-2763](https://doi.org/10.57996/cran.ceres-2763)

Extract the sequence used by the reported real-video experiments and place it at:

```text
dataset/video/250312-110206-video_1.mp4
```

The local file used to generate the reported results had the following properties:

```text
Size: 31,674,475 bytes
SHA-256: FB31C89F55186B7DA76FA871B3CF1259C5C964E48679D398B6BAE17B957CE7E6
```

This hash identifies the local experimental input and is not presented as an official WAAM-ViD checksum. See `dataset/README.md` for the full dataset citation, license, and metadata instructions.
